# 📅 Minsk Booking SaaS Bot

Бэкенд-приложение и Telegram-бот для автоматизации записи на бьюти-услуги (маникюр, педикюр, брови) в Минске. Проект разработан как гибкая SaaS-платформа для владельцев бизнеса с поддержкой личного кабинета директора и автоматической фильтрацией рабочего времени.

---

## 🛠 Технологический стек

* **Язык программирования:** Java 17
* **Фреймворк:** Spring Boot 3.3.4
  * Spring Data JPA (работа с базой данных)
  * Spring Web
* **База данных:** PostgreSQL (реляционная СУБД)
* **Библиотека Telegram API:** TelegramBots Starter (v10.2.1) cOkHttp-клиентом
* **Сборщик проекта:** Maven

---

## 🔥 Главные фичи (MVP Функционал)

### 👤 Для клиентов:
* **Авторегистрация:** Бот автоматически заносит ТГ-профиль нового клиента (ID, имя, username) в PostgreSQL при первом старте.
* **Динамический прайс-лист:** Список услуг ("Маникюр", "Педикюр", "Брови") и цены загружаются напрямую из базы данных.
* **Умный календарь дат:** Бот генерирует рабочие дни на 5 дней вперед, автоматически скрывая выходные дни салона.
* **Фильтрация времени:** 
  * Занятые окошки автоматически исчезают из меню выбора времени.
  * Бот скрывает прошедшие утренние часы для сегодняшнего дня, защищая от просроченных записей.
* **Личный кабинет («Мои записи»):** Просмотр активных будущих бронирований с возможностью **безопасной отмены визита** (удаление из базы данных).

### ⚙️ Для владельца бизнеса (Директора):
* **Многопользовательский админ-доступ:** Список Telegram ID директоров настраивается в файле конфигурации через запятую.
* **Панель директора:** Выводит полный журнал записей всех клиентов, автоматически отсортированный по хронологии (по дате и времени). Прошедшие дни скрываются для удобства.
* **Глобальное управление через `application.properties`:**
  * Изменение часов работы (например, с 8 до 20).
  * Выбор рабочих дней недели по битовой маске (например, `1,1,1,1,1,0,0`).
  * Настройка лимита активных записей на одну услугу для одного клиента (защита от спама).

## 🚀 Как запустить проект локально (на Ubuntu)

### 1. Подготовка базы данных PostgreSQL
Убедитесь, что PostgreSQL установлен и запущен. Создайте базу данных и задайте пароль суперпользователя:
```bash
sudo systemctl start postgresql
sudo -i -u postgres psql

# Внутри пульта управления psql:
CREATE DATABASE bookingdb;
ALTER USER postgres WITH PASSWORD 'ваш_надежный_пароль';
\q
```

### 2. Настройка конфигурации приложения
Откройте файл `src/main/resources/application.properties` и заполните параметры:
```properties
# Токен вашего бота от @BotFather
bot.token=ВСТАВЬТЕ_ТОКЕН_БОТА

# Настройки подключения к вашей локальной базе PostgreSQL
spring.datasource.url=jdbc:postgresql://localhost:5432/bookingdb
spring.datasource.username=postgres
spring.datasource.password=ваш_надежный_пароль

# Рабочий график и лимиты
business.work.start=8
business.work.end=20
business.work.days=1,1,1,1,1,0,0
business.max.bookings.per.service=2

# Telegram ID админов, у которых появится кнопка "Панель директора"
business.admin.ids=ВАШ_ТГ_ID,12345678
```

### 3. Сборка и запуск проекта
В терминале корневой папки проекта выполните:
```bash
# Скачивание зависимостей и компиляция
./mvnw clean compile

# Запуск Spring Boot приложения
./mvnw spring-boot:run
```
После запуска проект автоматически наполнит базу данных тестовыми бьюти-услугами, создаст все необходимые таблицы и бот станет доступен в Telegram!
